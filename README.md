# 高級腕時計ローンシミュレーター

ROLEXなどの高級腕時計購入時のローンシミュレーションを行うWebアプリケーション。

## 特徴

- 📊 **10店舗のローンプラン比較** - ウォッチニアン、かめ吉、GMT、ジャックロード、CLOSER、GINZA RASIN、大黒屋、KOMEHYO、ベティーロード、東京質舗
- 💰 **正確な計算** - 元利均等返済方式による精密な返済シミュレーション
- 📱 **レスポンシブデザイン** - スマホ、タブレット、PCに完全対応
- 🎁 **ボーナス払い対応** - ボーナス月加算の計算も可能
- 🔗 **結果共有** - URLで計算結果を簡単にシェア
- 📈 **詳細な返済表** - 月ごとの元金・利息内訳を表示

## 使い方

1. ブラウザで `watch_loan_simulator.html` を開く
2. 商品価格を入力（例: 1,500,000）
3. 頭金の割合をスライダーで調整（0%〜80%）
4. 返済回数を選択（3回〜60回）
5. 必要に応じてボーナス払いを設定
6. 「シミュレーション実行」ボタンをクリック

## カスタマイズ

### 店舗データの追加・変更

`watchStores` 配列を編集して、店舗情報を追加・変更できます:

```javascript
{
  id: "store-id",
  name: "店舗名",
  displayName: "表示用店舗名",
  logo: "🏪",
  loanPlans: [
    {
      planName: "プラン名",
      minAmount: 100000,
      maxAmount: 10000000,
      interestRate: 9.8,
      minMonths: 3,
      maxMonths: 60,
      availableMonths: [3, 6, 10, 12, 18, 24, 36, 48, 60],
      processingFee: 0,
      processingFeeType: "fixed",
      features: ["特徴1", "特徴2"]
    }
  ],
  url: "https://example.com/",
  note: "備考",
  recommendPoint: "おすすめポイント"
}
```

### カラースキームの変更

CSS変数（`:root`）を編集してカラーをカスタマイズできます:

```css
:root {
  --primary-color: #1a1a1a;
  --secondary-color: #c9a050;
  --accent-color: #2c5f8d;
  /* ... */
}
```

## 注意事項

- このシミュレーターは概算値を示すものです
- 実際の融資条件は審査により異なる場合があります
- 金利・手数料は変更される可能性があります
- 正確な情報は各販売店に直接お問い合わせください
